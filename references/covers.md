# 白洞 · 封面画法与逐期独立构图

2026-11-03：新期围绕商业经济问题设计封面。保留用户此前认可的三种画法、色盘和 V5 原生竖版效果；历史情绪冲突是旧案例，不再要求新期演绎。先看[三种风格总览](../assets/examples/cover-styles/contact-sheet.png)，再看 [V5 的 9:16 总览](../assets/examples/cover-v5/overview-9x16.jpg)与 [3:4 总览](../assets/examples/cover-v5/overview-3x4.jpg)，从本期案例对象、关键问题和数据差异设计独立画面，不轮换三套构图。

## 1. 三种风格怎样选

| 风格（保留历史名称） | 新期可表达 | 色彩参考 | 可借鉴的视觉关系（不绑定站位与字区） |
|---|---|---|---|
| A · 边界制止 | 费用、价格与经营约束 | 深蓝 `#111B35`、纸白 `#FFFDF5`、亮黄 `#FFE052` | 账目分区、物件边界和前后空间；可由商品、数字或主讲作主体 |
| B · 言语冲突 | 营收与利润、不同模式或对象的差异 | 朱红 `#ED533E`、酒红 `#552335`、墨黑 `#171719`、黄白强调 | 两类对象、金额或结果的对照，不要求双人对峙 |
| C · 行动离开 | 资金流、经营流程与时间变化 | 蓝 `#135CFF`、浅蓝 `#B8D1DC`、深蓝 `#182C46`、暖黄 `#FFE7A0` | 流向、路径和空间层次来自实际解释，不要求角色离开或逃避 |

历史示例分别为《别替我做主》《有道理，也不想听》《越劝，越想逃》。示例里的 B1 丁叔、D2 反问姐只属于这组样稿，不绑定三种风格。新期按主讲与题目选择是否展示 A1–D2，姓名、造型、识别配饰与声音以正式完整包的 `characters.md` 为准；若当前副本还只有旧双人模板，先按 `SKILL.md` 的本机入口读取正式八人包，不能重新映射成旧两人；不能因采用 B 风格就固定丁叔出场或把他改成父亲。重做历史视频封面时沿用该片实际角色，不擅自把原片老白、小问替换成八人阵容。V5 第 14 期沿用原片的 A2 跳跳、C1 流程哥。

每期先确定一个最能代表主题的画面，再选合适的配色。商品、账目、图表或经营关系均可作主体，不要求人物表演。主体大小、空间、视觉重心和字区形成明确变化，不只在同一头像旁更换小图标。批量制作时把全部缩略图同屏查看，去掉标题后仍应能区分各期；尤其拉开相近题材的构图。不能以换色、换标题、换小道具或给配置起不同名字冒充独立设计。用户要求比较时再为同一期做多个候选。

## 2. 先把封面内容写清楚

不要从知识名词、情绪标签或夸张形容词直接起标题。先读本期已确认的脚本，找到观众想弄懂的问题：研究谁、哪笔账有差异、什么现象需要解释。标题明确疑问，画面呈现关键对象或比较关系，不重复堆同一句解释。

在本期已有策划或封面记录里保留以下信息；不为此新增工作台数据库字段：

- **观众疑问**：这张图让人想弄明白的一个具体问题。
- **正文依据**：脚本的具体段落、关键事实与计算，指出视频在哪里兑现标题；不是只写一个文件名。
- **短标题与画面**：按语义断行的标题、强调词、案例对象与关键视觉关系；展示主讲时保持角色身份。
- **逐比例构图**：四尺寸各自的景别、主体与资料落点、字区；批量制作时记录与相邻题材的差异。

V5 的历史实例仅用于理解提炼方法和画法，不把旧选题、句式或情节套到下一期：

| 正文情境 | 已采用标题 | 需要在视频里解释的疑问 |
|---|---|---|
| 高薪同事的工作又交给自己，文件被推回 | 你工资更高 / 凭啥我干？ | 为什么我会抗拒替高薪同事兜底？ |
| 朋友升职，发出恭喜却笑不出来 | 他升职了 / 我却笑不出 | 为什么朋友成功会让我难受？ |
| 客户还没嫌贵，自己先降低报价 | 客户没嫌贵 / 我先打折了 | 为什么还没被拒绝，就先压低自己？ |
| 会议里早有想法，却等别人先说才附和 | 明明先想到 / 却只敢附和 | 为什么有想法却不敢先开口？ |

删去正文没有依据的指控、逆袭结果和万能承诺，不捏造企业恶意。标题的未解问题应在片中得到解释；营收不能当利润，假设金额不能当实际业绩。企业标识与资料素材按 `visual.md` 核对来源、许可与使用边界。若标题、画面和正文无法对齐，先改提炼，不靠更亮颜色或更多感叹号补救。案头推敲不能当作真实点击率测试。

## 3. 共同画法与原生竖版

- 延续 Lemo/scifi-toon：黑白灰人物、粗深色轮廓、平涂与硬边阴影。保留各人头型、发束、服装与配饰，不另画一套相似人物。
- 标题使用粗黑体/无衬线大字，通常两行，按意思断行，以手机缩略图仍可读为准；不为塞入解释而缩小字号。英语独立改写和排版，不能机械照搬中文断行。
- 按背景选纸白、亮黄或亮蓝关键词；不再强制“黑字 + 蓝色关键词 + 亮底”。深色背景配浅字，浅色背景配深字。标题硬阴影和描边克制，不能把字堆厚到影响辨认。
- 一张封面有一个最突出的对象或关系。主体与背景用大小、明暗、粗轮廓和适量浅色外描边分开；白洞标识小而清楚，不与标题争主次。
- 背景空间、实物或账目结构服务解释；只有涉及地点时才加场景细节。不要给每张都堆点阵、箭头、光效和装饰物。
- 气泡尾巴只指向真正说这句话的人。引用别人的话而未画说话者时，使用无尾巴引用标签，避免把话错安到出镜角色身上。
- 9:16 与 3:4 各自在目标画布上重新安排景别、动作空间和文字。3:4 需要调整角色大小与道具位置，不能简单裁短 9:16；竖版也不能由横版裁切、拉伸或四周补背景冒充。
- 放大本期最关键的商品、账目、差异或流向。人物出镜时手、视线与解释对象形成明确关系，不另演剧情。不要统一做成“上面两行字 + 一条小白标签 + 下面小人”，不能轮换固定站位。
- 删除重复解释的副标题与装饰标签；保留的短句应是关键话语或必要对象信息。为头发、手势、配饰与文字留出空间，重要信息避开画面边缘；根据实际平台预览检查遮挡，不假设一套固定安全区适用于所有平台。

## 4. 制作与尺寸

1. 按第 2 节记录观众疑问、正文依据、封面短标题、独立画面和逐比例构图，再选 A/B/C 的色彩参考；对照已有封面避免重复站位与字区。
2. 先看下方横竖实图，再在本期工程的 `cover.js` 中实际完成绘制，复用现有 `character()` 与角色库。封面是静帧，不更换正片制作引擎，也不连带修改正片的配色与字幕版式。
3. 模板里的 `cover.js` 仍包含旧式通用底稿，`COVER` 的旧字段仅负责已有接线；当前没有自动套用 A/B/C 的 `style` 参数。不能只写一个未被读取的字段就声称已接入。标题字重、字体、场景、姿态和颜色需要在本期代码里真正实现；新增文字时更新本期字库。
4. 用现有 `scripts/cover.sh` 经 Lemo 渲染导出：16:9 为 1920×1080，4:3 为 1440×1080，3:4 为 1080×1440，9:16 为 1080×1920。横竖各自排版，4:3、3:4 也要核对重排，不能机械拉伸或从横版直接裁切。
5. 批量重做时先完成少量不同题材的代表图，检查内容、角色和手机效果后再扩展。保留已有旧图和恢复点；封面重做不连带改动正片、音频或角色资产。
6. 随包参考是画法和构图实例，不把它们算作本期四尺寸已制作完成。英文封面需要对应英文文案及断行，不能用中文示例冒充交付。

## 6. 导出后检查

- **内容与差异**：多期同屏看，遮住标题后仍能区分主体、关系与景别；相近题材不重复构图。逐张核对标题、数字与正文依据；有角色或话语时核对身份与归属。
- **完整图与缩略图**：看原图，再看约 320px 宽缩略图和手机宽度显示。标题重点与案例对象应清楚；字、气泡不压脸或关键资料，头发、手、配饰和主体不意外出界。中文无缺字，英文无错误换行或标点挤压。
- **文件与比例**：逐一核对四种尺寸的实际文件、像素、语言与链接；不能用检查一个比例代替其余比例。若四张都是同一画面裁切或拉伸，即使尺寸正确也需要重排。
- **审阅页**：含竖版时让 9:16 默认可见，并提供明确比例切换；支持比例链接时验证其确实打开对应图。有旧图对比、缩略图按钮时实际点击。按约 320px 与 390px 视口检查 9:16 / 3:4，无横向溢出、丢图或失效链接。
- **变更边界与状态**：只改封面时检查正片、声音与角色资产未被连带覆盖。分别记录已检查、未检查和待修项；参考图齐全、封面检查通过，不等于整期视频已完成。

案头检查与用户暂用风格，不等于平台点击率或留存已验证。后续仅依据用户提供的实际指标与反馈修订，不承诺换封面必然提高表现。
