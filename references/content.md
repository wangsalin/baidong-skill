## 1. 选题分析与打分

先记录选题从哪里来、有什么可核对的需求信号，再填写下面的分析。来源和具体评论、账号、场景写入对应 `topics` 记录的 `source`、`sourceNote`；分析写入 `episodes` 的 `analysis`、`angle`、`mechanism`、`action`、`pitfalls`。不抓取或模拟登录平台。

| 项目 | 怎么判断 |
|---|---|
| 关系桶 | 1–5，可以多选，但主桶只有一个 |
| 共鸣（1–5） | 目标观众是否经历过、能否立刻认出这个时刻？5 = 熟悉而具体，1 = 很少遇到 |
| 冲突（1–5） | 现象、常见解释与可能机制之间有没有值得追问的落差？5 = 问题清楚且有可信答案，1 = 没有悬念。这里的“冲突”不是煽动争吵 |
| “和我有关”（1–5） | 是否命中账号的具体受众，而不只是泛泛地“人人都可能遇到”？5 = 对应清楚的人群和处境，1 = 与受众关系弱 |
| 需求信号 | 评论或私信原话、反复出现的生活问题、用户指定、对标作品表现等。写清看到的事实；没有就标记“需求未验证” |
| 主机制 | 一个可以一句话说清的规律。一期只用一个，其他的最多一句带过 |
| 可解释性 | 能否找到可靠证据说明机制，并给出生活场景或画面呈现？ |
| 小动作 | 观众今天就能做的一件具体的事 |
| 要避开的坑 | 红线（投资、医疗、法律、点名、嘲笑群体）和容易讲歪的方向（成功学、鸡汤、玄学） |

工作台三项总分满分 15 分；12 分以上只用于优先排序，不自动通过立项。出现以下任一情况先换角度或暂缓：说不出具体受众和生活时刻；题目没有明确问题或看完的收获；机制找不到可信证据；答案需要堆多个互不相关的机制。用户直接给出的选题仍可继续分析，但要如实写出需求信号尚未验证，不能把主观评分说成市场验证。

### 立项前比较三个角度

围绕同一选题提出三个真正不同的讲法，不要只改写标题。可从具体场景、解释落差、人物选择或后果影响切入。每个角度写成一张简卡：

- 面向谁、发生在什么时刻
- 开场钩子和观众会继续追问的问题
- 片子准备怎样回答：机制、证据、案例或视觉揭示
- 看完观众得到什么
- 主要风险：证据不足、受众太泛、承诺过大或情绪处理不当

比较后选一条最具体、最可信、最能兑现收获的角度。记录在现有 `analysis` / `angle` 字段，不新增数据库字段。若三个角度都只是在重复同一个泛化观点，回到选题本身重找场景。

## 2. 3 秒钩子

确定角度后写 3 个不同类型的开头，挑最能兑现内容承诺的一个。开头第一句就是全片第一句台词，第一帧就有字幕和动作，不放片头。

| 类型 | 写法 | 例子 |
|---|---|---|
| 戳痛点 | 点出观众不愿承认的感受 | “你身边一定有这么个人：能力不如你，赚得比你多。” |
| 反常识 | 推翻一个人人都信的说法 | “收入，从来就不是按能力发的。” |
| 报问题 | 把观众心里的问题大声问出来 | “你有没有偷偷算过：凭什么是他？” |
| 点名身份 | 让某类人觉得“在说我” | “在外地打工、过年不想回家的人，可以停一下。” |
| 悬念 | 先给结果，不给原因 | “老人买保健品，买的其实不是药。” |

好钩子先做到：观众知道这说的是谁或什么处境；一句话里出现具体问题、意外落差或未解答案；后续内容确实能回答它。15 个字以内是优先尝试的写法，不是硬性指标。与标题和封面围绕同一个承诺，但不必逐字相同；不能用夸张结论吸引点击后再讲另一个话题。

选择钩子时并排看“具体度、好奇心、可信度、后文兑现度、受众贴合度”，说明为什么这一条更合适。只凭“最狠”“最短”不能作为选定理由。钩子、标题和封面都是同一内容承诺的不同表达。

## 3. 六段结构与字数预算

六段是策划和工作台的通用骨架，叙事方法按选题调整，不要求每期都有错误认知或强行反转。可用追问与验证、案例推进、选择对照、前后变化等结构。目标 4 分钟（3–5 分钟都可以）；老白语速约每秒 5 个字、小问稍快，900–1100 字只是 4 分钟的初估。以实际配音时长和内容完整度决定长度，不扩写凑字数，也不加空镜头撑时长。

| 段落 | 时间 | 字数 | 要做到什么 | 留存手段 |
|---|---|---|---|---|
| s1 钩子 | 0–3 秒 | 按语速 | 抛出具体处境或问题，并开启一个真实的未解疑问 | 第一帧就有字幕和动作 |
| s2 代入 | 3–20 秒 | 按内容 | 展示真实、可识别的场景，让观众知道本片会回答什么 | 建立内容承诺，不重复钩子 |
| s3 问题展开 | 约 20–60 秒 | 按内容 | 让问题变具体；只有确有常见误解时才推翻它 | 给出下一步值得看的原因 |
| s4 解释与验证 | 约 1:00–2:40 | 按内容 | 在角色经历、对照或尝试中讲清一个主机制，配 2–3 个功能不同的案例或证据 | 解释跟着情节走，每个案例都增加解释、检验或限制，不连成一段授课 |
| s5 意义落点 | 约 2:40–3:30 | 按内容 | 呈现角色理解前后的反应或选择，让观众看见与自己处境的联系 | 用反应、动作和结果呈现，不用固定安慰句或强行升华 |
| s6 回答与行动 | 约 3:30–4:00 | 按内容 | 回答开头的问题，给一个可执行的小动作或明确结论，再提出自然的评论问题 | 兑现开头承诺；片尾固定语“下一个为什么，白洞见。” |

片头（2 秒，黑点扩散出圆环、“白洞 No.xx”和本期问题）放在 s1 之后、s2 之前。时长范围用于预估，不得为了填满某段而拖慢信息推进。

## 4. 对话怎么写

### 写稿前：先搭一个场景引擎

先写一张简短场景卡，再写对白。不要从“我要解释什么概念”直接起稿。场景卡要能回答：

- 主角现在具体想做什么？目标要能拍出来，不写“想明白人生”这类抽象愿望。
- 谁或什么挡住了他？如果暂时不处理，会马上失去什么、错过什么或继续承受什么？代价要真实、看得见，不为刺激而夸大。
- 什么意外或决定让这件事此刻必须解决？第一句和第一帧尽量从这个动作切入。
- 局面怎样一步步变化？每次推进至少改变信息、筹码、风险、关系或可选行动中的一项。
- 哪个新证据或发现让人物不得不改判断、改计划或承担后果？证据只回答它实际能回答的问题。
- 人物最后做了什么选择，产生什么看得见的结果？机制解释要帮观众看懂这个结果，不另起一段讲课。

冲突可以发生在人与人之间，也可以来自人物自己的拉扯、规则、时间或物件；没有真实分歧就不要硬写吵架，也不要编造极端后果。情景可以虚构演绎，但不能包装成真实个案或研究。若场景卡只有“举个例子 → 说出术语 → 总结道理”，先换角度，不要直接扩成脚本。

例：平铺写法是“小问嫌电影难看，老白解释沉没成本”。可演的构思可以是电影票已退不了、末班车将到，小问想走，老白因票钱已经付了坚持看完；新的时间信息迫使两人重新比较“已经花掉的”和“接下来还要付出的”，再由选择和后果带出机制。这是虚构的构思示例，不是必须照搬的剧情模板。

- **先有事发生**：先写清人物想做什么、遇到什么麻烦或意外，再让观众跟着追问原因。解释穿插在行动、选择和后果里，画面要能演出事情的变化。
- **有戏剧冲突的题先试情景争执**（2026-10-27 用户偏好）：先写清两人此刻各想要什么、谁拦住了谁、被拒绝会失去什么。允许顶嘴、抢话、误解和让步，原因从双方已有经历和行动后果里显露。老白可以有自己的利益、盲点和说错的话，小问能反驳并改变事情的结果。争执需要推进、转折和具体结果，不以持续喊叫或人身羞辱代替剧情，不强迫所有主题都吵架。
- **老白**通常负责帮观众看懂机制：话少、慢、冷面，偶尔冷幽默。情景戏里可直接参与冲突，沿自己的经历说话；不固定成永远正确的老师。短解释后回到行动和结果，避免连续授课。
- **小问**代表观众，也有自己的猜测、尝试和选择：会急、会不服、会恍然大悟。她的行动或追问推动下一段，不只是替老白递话的提问工具。
- 笑点只落在两个主角身上（小问的过度反应、老白的冷吐槽）。不拿任何真实群体、疾病、死亡、贫困开玩笑。
- 每句台词不超过 30 字；长句拆给两个人说。一句只讲一件事。
- 每 20–30 秒左右要有一次内容推进：新证据、具体后果、选择变化、反例或视觉揭示。画面可以帮助推进，但单纯切镜头不算新信息。
- 机制段通常用 2–3 个例子；每个例子承担不同作用，优先选择观众熟悉、能画出来的生活场景。不要把一个证据改写成多个相似故事来凑时长。
- **直接讲清概念和原理**：以解释名词或机制为题时，正文必须用口语直接说出“它是什么、什么条件下适用、为什么导致眼前的结果”；再通过角色的选择说明接下来应比较什么。不能用情绪、金句或暗示代替必要解释，也不能让观众看完只记得吵架。
- **首次出现先交代所属体系**：专业名词、人格维度、英文缩写或字母组合第一次出现时，先说它属于什么体系，再说每个字母或名词是什么意思，最后说明它能解释什么、不能解释什么。例如不要只说“T/F”，要先说“MBTI 十六型人格里的 T/F 偏好”，再解释 T 是思考型、F 是情感型；画面和口播在同一段完成这层定位。若观众只听前 20 秒，仍应知道本片讲的对象是什么。
- **区分概念与行为**：例如沉没成本是已经付出且当前选择无法收回的代价；因为舍不得这笔投入而继续，是它影响判断的表现。说明应比较未来的新增成本和收益，有沉没成本不等于必须放弃。其他主题同样交代会改变结论的条件。
- **画面支持理解**：先用熟悉的物件和动作建立处境；按 `visual.md` 把需要比较的关系变成可见变化。科幻装置服务于原理，不增加妨碍理解的设定。
- 删掉“我们应该”“你要明白”“人生就是”等训话和泛泛拔高。让角色的新选择、可见的结果或一件可试的小事承接结尾。
- 趣味来自好奇、意外、角色反应和互动；按题目选择，不硬塞笑话，不用装可爱代替内容。故事和类比仍须守住事实边界。
- 数字配音时写成汉字（`say` 字段），字幕里用阿拉伯数字（`text` 字段）。
- 容易被听错的词要换说法（上一期“头版”总被听成“头吧”，改成了“上了报纸”）。

## 5. 留存自查清单

脚本写完逐项过一遍，写进工作台的 `check` 字段。清单是编辑诊断工具，不按勾选数量判定稿件好坏：

- [ ] 第一句在 3 秒左右能听懂，指出具体对象、处境或问题
- [ ] 钩子、标题和封面表达同一个可兑现的承诺，没有误导
- [ ] 20 秒内说明本片会回答什么，同时留下值得继续看的问题
- [ ] 第一次出现的专业名词、人格维度或缩写已先交代所属体系，并用口语解释含义与边界
- [ ] 按孩子也能听懂的标准朗读：不懂专业词也能跟上谁遇到了什么事，并能说出下一步想知道什么
- [ ] 若使用“你以为……其实……”，两边都真实存在且有证据，不为格式硬造误解
- [ ] 整期只有一个主机制，能用一句话复述
- [ ] 机制段的案例各自承担新作用，证据范围和限制讲准确
- [ ] 小问有自己的想法和行动，老白的解释回应眼前的问题；没有两个人轮流念讲义的段落
- [ ] 观众能用一句话说清主角现在要什么、被什么拦住、拒绝或拖延会付出什么代价
- [ ] 每次情节推进都改变信息、筹码、风险、关系或可选行动中的至少一项；没有变化的对白可删或合并
- [ ] 机制解释贴着人物当下的选择和结果；拿掉术语后，事件仍然讲得通、看得下去
- [ ] 若采用争执戏，双方目标和理由都清楚，争执改变了局面；结尾回应开场选择及其后果，而不只是停在一句道理上
- [ ] 每 20–30 秒左右有实质内容推进，不把换镜头当成推进
- [ ] 第 5 段对观众处境有真实意义；删掉说教和升华句后，仍有具体事件、反应和收获
- [ ] 结尾回答开头的问题，具体行动和开头承诺一致
- [ ] 观众能用大白话复述名词的含义、适用条件和因果；没有把概念与受它影响的行为混为一谈
- [ ] 科幻表达、人物操作和可见结果共同帮助理解；真实数据与虚构演绎清楚区分
- [ ] 对话紧凑，关键定义没有被抢话盖住；停顿有具体动作、反应或转折，时长经过带声播放检查
- [ ] 小动作具体到今天就能做
- [ ] 评论区问题是二选一、对号入座或讲经历中的一种
- [ ] 没有踩红线；所有数字都在 FACTS.md 里有出处
- [ ] 预估语音时长与内容实际需要相称；900–1100 字只作为约 4 分钟的参考

## 6. 事实表

`FACTS.md` 一行一条：台词里的说法 → 出处链接 → 原文摘录（或测量方法）→ 证据与台词的关系。规则：

- 只用打开过的页面，不用搜索摘要。
- 学术结论优先找论文或权威机构页面；新闻只用于事件本身。
- 查不到出处的数字或研究结论删掉或缩窄到有证据支持的说法；不能用“好几倍”“很多人”掩盖缺少证据。生活类比明确是示例，不伪装成研究结果。
- 有争议的说法加“一种解释是”。
- 标明台词属于原研究直接结果、基于研究的解释，还是生活类比；不要让一条研究看起来支持它没有研究过的状态或人群。
- 记录会改变结论的适用条件和争议；必要时缩窄台词，不用讲故事的顺滑度覆盖证据边界。
- 同步写进工作台 `facts` 字段（每条 `{o, claim, url}`）。

## 7. 标题、封面文案、评论区

**封面大字**：不超过 12 个字为宜，分两行（用 `/` 分隔），最戳人的一个词用克莱因蓝（写进 `coverHighlight`）。同时在 `story.js` 的 `COVER.bg` 和 `COVER.pop` 为本期选两种高对比色：背景用明亮且饱和的颜色，人物背后用撞色形状；黑字和蓝色关键词必须清楚可读。不同期轮换色组，不要每期都用同一套黄红，也不要让画面变成无层次的彩虹。

**各平台标题**（写进 `mat.<平台>.title`）：

| 平台 | 写法 | 长度 |
|---|---|---|
| B 站 / YouTube | 问题 + 反转或机制名，可以长 | ≤ 80 字 |
| 抖音 / 快手 | 短、带情绪、口语 | ≤ 30 字 |
| 小红书 | 第一人称、带感受词（“终于想通了”“原来……”） | ≤ 20 字 |
| 视频号 | 家庭类选题写成“转给爸妈看”的口吻 | ≤ 30 字 |

**简介**（`mat.<平台>.desc`）：三句话——本期问题、核心机制一句话、评论区问题。B 站和 YouTube 后面附章节。

**标签**（`mat.<平台>.tags`）：3–6 个，空格分隔，包括 `#白洞`、选题关键词、领域词（心理学 / 经济学 / 社会学）。

**评论区置顶语**：一句片中没说完的补充，引导讨论。

**小红书 6 张卡片**（`xhsCards`，每张 `{o, head, body}`）：1 封面问题 → 2 你一定经历过的场景 → 3 你以为的原因 → 4 真正的机制 → 5 今天就能做的小动作 → 6 评论区问题。每张 head ≤ 12 字，body ≤ 60 字。
