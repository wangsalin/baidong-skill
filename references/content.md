## 1. 选题分析与打分

先记录选题从哪里来、有什么可核对的需求信号，再填写下面的分析。来源和具体评论、账号、场景写入对应 `topics` 记录的 `source`、`sourceNote`；分析写入 `episodes` 的 `analysis`、`angle`、`mechanism`、`action`、`pitfalls`。不抓取或模拟登录平台。

| 项目 | 怎么判断 |
|---|---|
| 关系桶 | 1–5，可以多选，但主桶只有一个 |
| 共鸣（1–5） | 目标观众是否经历过、能否立刻认出这个时刻？5 = 熟悉而具体，1 = 很少遇到 |
| 冲突（1–5） | 现象、常见解释与可能机制之间有没有值得追问的落差？5 = 问题清楚且有可信答案，1 = 没有悬念。这里的“冲突”不是煽动争吵 |
| “和我有关”（1–5） | 是否命中账号的具体受众，而不只是泛泛地“人人都可能遇到”？5 = 对应清楚的人群和处境，1 = 与受众关系弱 |
| 需求信号 | 评论或私信原话、反复出现的生活问题、用户指定、对标作品表现等。写清看到的事实；没有就标记“需求未验证” |
| 主机制 | 一个可以一句话说清的规律。一期只用一个，其他的最多一句带过 |
| 可解释性 | 能否找到可靠证据说明机制，并给出生活场景或画面呈现？ |
| 看完收获 | 生活题给一个可尝试的小动作，并说明它解决什么、不能保证什么；历史、科学特别企划给一个解释清楚的答案或判断方法，不硬套生活建议 |
| 要避开的坑 | 红线（投资、医疗、法律、点名、嘲笑群体）和容易讲歪的方向（成功学、鸡汤、玄学） |

工作台三项总分满分 15 分；12 分以上只用于优先排序，不自动通过立项。出现以下任一情况先换角度或暂缓：说不出具体受众和生活时刻；题目没有明确问题或看完的收获；机制找不到可信证据；答案需要堆多个互不相关的机制。用户直接给出的选题仍可继续分析，但要如实写出需求信号尚未验证，不能把主观评分说成市场验证。

关系桶和生活时刻的判断用于日常生活题。用户明确指定历史、科学特别企划时，在现有 `analysis` 中注明特别企划、目标观众和知识疑问；不为套评分虚构生活痛点，不把它自动扩成账号长期方向。

### 立项前比较三个角度

围绕同一选题提出三个真正不同的讲法，不要只改写标题。可从具体场景、解释落差、人物选择或后果影响切入。每个角度写成一张简卡：

- 面向谁、发生在什么时刻
- 开场钩子和观众会继续追问的问题
- 片子准备怎样回答：机制、证据、案例或视觉揭示
- 看完观众得到什么
- 主要风险：证据不足、受众太泛、承诺过大或情绪处理不当

比较后选一条最具体、最可信、最能兑现收获的角度。记录在现有 `analysis` / `angle` 字段，不新增数据库字段。若三个角度都只是在重复同一个泛化观点，回到选题本身重找场景。

### 起稿前：确定观众究竟卡在哪里

在本期 `TREATMENT.md`（或现有策划记录）中写清：观众带着什么具体疑问进来；看完应能怎样回答；要理解这个答案，中间还必须弄懂哪些问题。只保留服务于主问题的追问，不把一期扩成知识大全。

例如“通古斯为什么没有典型撞击坑”，不能只答“因为是空爆”。观众还会问：天体为什么会在空中解体？没撞到地，什么力量推倒了树？这些解释凭什么可信、哪些细节仍不确定？每个关键追问都要在正文找到回答，不能只出现在策划里。

生活题也一样：“开会不敢先说想法”不能停在“你缺乏自信”。要解释当事人想被看见、又担心什么，以及为什么“等别人说了再附和”暂时更安全；最后的小动作应针对这个阻碍。心理学框架可以辅助解释，不能把虚构的内心对白当作对每个人的诊断。

## 2. 3 秒钩子

确定角度后写 3 个不同类型的开头，挑最能兑现内容承诺的一个。开头第一句就是全片第一句台词，第一帧就有字幕和动作，不放片头。

| 类型 | 写法 | 例子 |
|---|---|---|
| 戳痛点 | 说出具体时刻里难以启齿的感受 | “同事一开口，我的点子就成了附和。” |
| 反常识 | 呈现有依据的现象落差 | “树倒了一大片，却没找到撞击坑。” |
| 报问题 | 把观众心里的问题大声问出来 | “明明先想到了，怎么就不敢先说？” |
| 点名处境 | 让观众认出自己的动作 | “开会举了一半的手，你也放下过？” |
| 悬念 | 先给具体结果，留下待解释的问题 | “石头没砸到地，树怎么倒了？” |

好钩子先做到：观众知道这说的是谁或什么处境；一句话里出现具体问题、意外落差或未解答案；后续内容确实能回答它。15 个字以内是优先尝试的写法，不是硬性指标。与标题和封面围绕同一个承诺，但不必逐字相同；不能用夸张结论吸引点击后再讲另一个话题。

选择钩子时并排看“具体度、好奇心、可信度、后文兑现度、受众贴合度”，说明为什么这一条更合适。只凭“最狠”“最短”不能作为选定理由。钩子、标题和封面都是同一内容承诺的不同表达。

3 秒是让人认出问题、产生继续看的理由，不是塞完背景或喊一个结论。不要拿“震惊”“真相终于曝光”、绝对断言或不存在的科学争议制造悬念。留存效果要靠真实发布数据验证，文案复核不能宣称提高了多少留存率。

## 3. 六段结构与字数预算

六段是策划和工作台的通用骨架，叙事方法按选题调整，不要求每期都有错误认知或强行反转。可用追问与验证、案例推进、选择对照、前后变化等结构。下表是约 4 分钟横版的参考（3–5 分钟都可以），900–1100 字只是初估；实际语速以所选正式角色的固定配音参数为准。以真实配音时长和内容完整度决定长度，不扩写凑字数，也不加空镜头撑时长。

| 段落 | 时间 | 字数 | 要做到什么 | 留存手段 |
|---|---|---|---|---|
| s1 钩子 | 0–3 秒 | 按语速 | 抛出具体处境或问题，并开启一个真实的未解疑问 | 第一帧就有字幕和动作 |
| s2 代入 | 3–20 秒 | 按内容 | 展示真实、可识别的场景，让观众知道本片会回答什么 | 建立内容承诺，不重复钩子 |
| s3 问题展开 | 约 20–60 秒 | 按内容 | 让问题变具体；只有确有常见误解时才推翻它 | 给出下一步值得看的原因 |
| s4 解释与验证 | 约 1:00–2:40 | 按内容 | 在角色经历、对照或尝试中讲清一个主机制，补上关键因果和必要证据 | 每个案例增加解释、检验或限制；不靠报出机制名称跳过原因 |
| s5 意义落点 | 约 2:40–3:30 | 按内容 | 呈现角色理解前后的反应或选择，让观众看见与自己处境的联系 | 用反应、动作和结果呈现，不用固定安慰句或强行升华 |
| s6 回答与行动 | 约 3:30–4:00 | 按内容 | 回答开头的问题，给一个可执行的小动作或明确结论，再提出自然的评论问题 | 兑现开头承诺；片尾固定语“下一个为什么，白洞见。” |

片头（2 秒，黑点扩散出圆环、“白洞 No.xx”和本期问题）放在 s1 之后、s2 之前。时长范围用于预估，不得为了填满某段而拖慢信息推进。

一分钟以内的竖屏缩减版不套这张分钟表，也不必呈现六个独立段落。保留一个能代入的具体时刻、一条讲完整的因果链和兑现开头的结尾；先删重复反应、旁支知识和无用接话，不删掉理解答案必需的中间步骤。时长与开场方式按 `vertical.md`，不能只靠加速配音把长稿塞进去。

### 整篇为什么值得继续听

起稿时把核心推进用几句话连起来：观众先看见什么、因此想知道什么；哪次发现改变了原来的理解；最后怎样回答开头。检查关键转折能否自然接上，不要求每段造一个新悬念，也不用问号数量判断吸引力。六段分齐、事实讲对，都不能替代这条推进。

- **从有意味的现场进入**：先给能想象的动作、异常或选择，让观众想问原因。年份、人物履历、概念定义只有在影响当前判断时才放进这一步；其余背景可以后置或交给画面。开头承诺的是一个值得解开的具体问题，不是“今天给大家介绍一个知识”。
- **让观众先有判断，再看到它哪里不够**：提供足够线索，让人能跟着猜、比较或期待；新发现应补全或修正这个判断。人物的猜测要像真实反应，不能为了反转故意说蠢话，也不能把未证实的看法写成科学共识。
- **边推进边兑现**：及时给出当前疑问的实质答案，再深入它自然带来的问题。例如讲出“在空中解体”后，接着回答“没落地，怎样造成地面破坏”。不把已经可以说清的答案藏到最后，不用“更惊人的还在后面”替代新内容。
- **每段的作用要有区别**：下一段应带来新线索、解释上的进展、人物选择或结果的变化。一个事实换三种说法、连续报几个数字、重复震惊，都可能让稿件原地打转。知识点的出场顺序跟着观众此刻想弄懂的事走，不照资料目录念。
- **共鸣写进经历**：生活题让人听见熟悉的迟疑和自我辩解，例如“你把开头那句在心里改了三遍，同事先说了，你只剩一句‘我也是这么想的’”。历史科学题可以让人经历猜测、观察和修正判断的过程，不硬套个人焦虑。情绪应随事情发展，不靠固定插入安慰句或笑话。
- **前一句把后一句带出来**：转折和承接要有具体关系。报完年代忽然解释原理、抛出名词立即总结，都是需要检查的断口。可以承接同一动作、拿新线索检验刚才的猜测，或回答上一句真正留下的疑问；不反复用“那么问题来了”“接下来”“真正可怕的是”当过桥句。
- **读起来像人在讲一件事**：使用明确的人、物和动作，少用“机制、现象、层面”等抽象词串联全文。解释、观察和反应可以有不同长短；给重要发现落下来的空间，再接下一层。保留角色有辨识度的判断与措辞，不靠口头禅和方言词堆性格；也不把所有台词切成一样短的碎句。
- **结尾让开头有了新含义**：回到最初的动作、问题或线索，让观众看清理解前后差在哪里，并把答案说完整。回扣服务于理解，不强求金句、反转或悬而不答；收获兑现后及时结束。

这套方法同样适用于主讲、吐槽、争执和穿越，不是固定剧情模板。选题本身缺少值得解释的疑问时，应收窄或重选角度；不能靠文案手法把薄弱内容包装成惊天秘密。

## 4. 对话怎么写

### 用场景或线索带着问题前进

先根据题目写一张简短场景卡或线索卡，再写对白。生活情景重点回答：

- 主角现在具体想做什么？目标要能拍出来，不写“想明白人生”这类抽象愿望。
- 谁或什么挡住了他？继续这样会有什么具体影响？可以只是说完附和后的失落，不必马上失业、丢钱或遭遇倒计时。
- 哪个动作或变化把这个问题暴露出来？第一句和第一帧尽量从这里切入，不为开场硬造紧急事件。
- 局面怎样一步步变化？每次推进至少改变信息、筹码、风险、关系或可选行动中的一项。
- 哪个新证据或发现让人物不得不改判断、改计划或承担后果？证据只回答它实际能回答的问题。
- 人物最后做了什么尝试，产生什么可见结果？结果可以只是先开口一句，不编造“一试就成功”。机制解释要帮观众看懂这个变化。

冲突可以发生在人与人之间，也可以来自人物自己的拉扯、规则或物件；没有真实分歧就不要硬写吵架。共鸣来自可识别的动作、心里犹豫和后果，不靠反复说“太真实了”“你不是一个人”。情景可以虚构演绎，但不能包装成真实个案或研究。

历史、科学特别企划用线索卡：眼前有什么可见异常；人物最初怎样理解；哪条资料或观察让原来的解释不够用了；更好的解释怎样说明现象；还有什么不能确定。悬念可以来自认知落差，不必给人物编造调查期限、危险或损失。穿越角色只负责引导观察和提问，不能靠科幻扫描器“测出”史料没有的事实；不能让现代角色成为真实历史发现的来源。此类内容沿用白洞的通俗表达和角色表演，不因此改成账号默认主赛道。

场景卡或线索卡里的关键变化必须能在稿中找到。只有“举个例子 → 说出术语 → 总结道理”时，应补出尝试、解释或验证，不靠增加对白轮次伪装推进。

例：平铺写法是“跳跳嫌电影难看，阿津解释沉没成本”。可演的构思可以是电影票已退不了、末班车将到，跳跳想走，阿津因票钱已经付了坚持看完；新的时间信息迫使两人重新比较“已经花掉的”和“接下来还要付出的”，再由选择和后果带出机制。这是虚构构思，不是每题都要套的倒计时模板。

### 先定主讲，再安排谁真正需要开口

新期按 `characters.md` 的八位正式人物选角，姓名、性格、说话方式和声音都沿用注册表。每期明确谁主讲、谁提问或短接；主讲承担主要解释并能连续表达，不固定搭档，也不为展示八个声音让所有人轮流出场。老白、小问只兼容旧期。

- **主讲 + 追问**：主讲沿一条思路讲，辅助角色只在真实理解断点、证据变化或情绪转折处开口。不要每讲一句就切人。
- **吐槽型**：主讲从一连串具体遭遇或矛盾里说中困惑，再解释为什么会这样、能改变哪一步。吐槽针对情境和自己的反应，不攻击真实群体；包袱不能挤掉答案。
- **情景争执**：题目有真实分歧时，双方各有目标、理由和盲点，争执改变选择或结果。允许顶嘴、误解和让步，不以持续喊叫代替剧情；没有分歧时不强套。
- **追查或穿越型**：主讲组织线索，同行角色替观众质疑、尝试或发现反常处。以证据推进解释，不能由“我懂了”直接跳到下一景。

这些是可选讲法，不要求每期比较全部形式。角色可以混搭，但不能因承担“专家”或“吐槽”功能就改掉其性格。辅助台词应带来新疑问、证据、选择或具体反应；删去后既不影响理解也不影响人物经历的接话，直接删掉。正式配音台词标好角色 ID，并在分镜中保证谁说话谁出镜。

### 因果要讲到观众能接上下一步

- **讲清关键因果**：把主解释写成能读通的一条因果链，逐个追问“为什么这一步会引起下一步”。“能量释放”“心理防御”这样的词本身不是解释；说清谁、发生什么变化、怎样造成眼前的结果。只补理解必需的层次，不无限展开新知识。
- **句子短，意思要完整**：一句尽量只推进一件事，按自然口语和换气拆句，不设单句字数硬上限；同一解释拆成几句仍由同一主讲说。字幕换行或音频分句不是换人的理由。
- 笑点来自出场角色的性格、误判和反应。不拿任何真实群体、疾病、死亡、贫困开玩笑。
- 内容推进来自新证据、具体后果、选择变化、反例或视觉揭示。中视频可用约 20–30 秒作粗查：若一段时间里理解和局面都没有变化，就检查是否该删并或补足；不按秒数硬塞反转、问题或笑点，单纯切镜头不算新信息。
- 案例按解释需要安排：中视频可用 2–3 个功能不同的案例或证据；短片往往沿一个场景讲透即可。每个案例增加解释、检验或限制，不把同一证据改成多个相似故事凑时长。
- **直接讲清概念和原理**：以解释名词或机制为题时，正文必须用口语直接说出“它是什么、什么条件下适用、为什么导致眼前的结果”；再通过角色的选择说明接下来应比较什么。不能用情绪、金句或暗示代替必要解释，也不能让观众看完只记得吵架。
- **名词先让人听懂**：首次出现时用口语解释它在本片是什么意思。依赖分类体系的人格维度、缩写或字母还要交代所属体系，例如“MBTI 十六型人格里的 T/F 偏好”，再解释 T、F；不把分类工具当作对个人行为的确定诊断。普通科学词不必绕到学科介绍，先说清作用和相关条件，画面同步标注。
- **区分概念与行为**：例如沉没成本是已经付出且当前选择无法收回的代价；因为舍不得这笔投入而继续，是它影响判断的表现。说明应比较未来的新增成本和收益，有沉没成本不等于必须放弃。其他主题同样交代会改变结论的条件。
- **画面支持理解**：先用熟悉的物件和动作建立处境；按 `visual.md` 把需要比较的关系变成可见变化。科幻装置服务于原理，不增加妨碍理解的设定。
- **先回答，再收尾**：结尾用具体因果兑现开头的问题；生活题再落一个针对阻碍、能尝试的小动作，历史科学题可停在解释和必要的不确定性上。“先抬头，再低头”这类金句不能代替“为什么没坑、树却倒了”的回答。删掉“我们应该”“人生就是”等训话和泛泛拔高，评论问题不必每次挤进短片口播。
- 趣味来自好奇、意外、角色反应和互动；按题目选择，不硬塞笑话，不用装可爱代替内容。故事和类比仍须守住事实边界。
- 数字配音时写成汉字（`say` 字段），字幕里用阿拉伯数字（`text` 字段）。
- 容易被听错的词要换说法（上一期“头版”总被听成“头吧”，改成了“上了报纸”）。

## 5. 文案推敲与留存复核

初稿后先按下面的方法编辑，改完重读受影响的前后文。把实质问题、对应句子和修改理由简记在 `TREATMENT.md`，工作台 `check` 字段写复核结果。不要求固定轮数，也不以“自评通过”替代修改证据。

先通读全篇，找出最可能让人失去兴趣的具体段落，并说明原因：问题尚未成立就铺背景、已经知道答案还在重复、连续抽象解释、转场没有关联，还是人物只在接话。针对实际问题调整顺序、删并或补出发现，重读后再看前后是否接得上。不为每句额外制作评分表；这是编辑判断，不是观众行为实测。

1. **沿观众的疑问读**：暂不看策划和分镜说明，只读台词。在每次“所以”“其实”“原来”前问一句“凭什么”。若理解必须依赖台词没说出的知识，把具体断点标出来并补足。画面可承担空间关系、比较或变化，但不能把核心原因全藏在说明图里。
2. **沿人物的经历读**：核对场景卡或线索卡里的变化是否真的发生。删除空接话、重复震惊和只喊术语的包袱；保留有作用的犹豫、动作和反应。主讲连读应有完整思路，辅助角色开口应有必要。按注册表看不同人物是否说得像自己。
3. **从结尾倒查开头**：用不带术语的一句话回答开场问题，再回到正文找每一步依据。答不出、答偏了或答案只能在金句里猜到，就改正文或收窄承诺。同步核对事实边界、小动作与适用条件，最后按角色语气朗读和预估时长；有试配音后再核实际时长。

例如，初稿写“石块破碎、减速，在空中释放能量”，编辑要指出“破碎、减速怎样造成地面破坏”尚未接上，而不是只标“原理清楚”。修改应补出能量传给周围空气、形成向外传播的冲击波这一环，再明确推倒树的是冲击波；没有典型撞击坑与没有发生大规模破坏是两回事。物理表述仍须核验，不把这个示例当作事实来源。

对观众做的理解复述是案头编辑，不是用户测试；没有真实试听或发布数据时，不声称观众都听懂了、留存提升了。

交稿前确认以下结果，失败项要回到具体句子修改：

- [ ] 开头约 3 秒能听懂具体问题或处境；标题、封面与正文兑现同一承诺，没有绝对断言或伪造误解
- [ ] 整篇有连贯的追问与兑现：关键转折带来新的理解或人物变化；最易失去兴趣的段落已定位并调整，没有只改开头、正文继续念资料
- [ ] 关键追问都有正文回答；名词有口语含义，必要的体系、适用条件和因果没省略，拿掉术语仍能讲通
- [ ] 生活场景有可识别的动作和情绪；历史科学线索有依据，没有靠假危机或科幻装置替代证据
- [ ] 本期主讲清楚、思路连续；辅助对白有作用，角色姓名、语气和分镜出镜关系正确
- [ ] 各次推进增加信息、选择或结果；没有为轮流说话、凑时长或塞笑点停住解释
- [ ] 若采用争执戏，双方目标与理由成立，争执改变局面；没有只吵架不解释
- [ ] 结尾明确回答开头；生活小动作针对实际阻碍且不保证效果，特别企划没有强行上价值
- [ ] 事实、解释、类比、虚构清楚区分；关键说法与数字有已核对出处，没有把推测写成定论
- [ ] 口语和字幕都能跟上，关键解释没被抢话盖住；时长与画幅相称，试配音后的修改没有漏核

## 6. 事实表

`FACTS.md` 一行一条：台词里的说法 → 出处链接 → 原文摘录（或测量方法）→ 证据与台词的关系。规则：

- 只用打开过的页面，不用搜索摘要。
- 学术结论优先找论文或权威机构页面；新闻只用于事件本身。
- 查不到出处的数字或研究结论删掉或缩窄到有证据支持的说法；不能用“好几倍”“很多人”掩盖缺少证据。生活类比明确是示例，不伪装成研究结果。
- 有争议的说法交代证据支持到哪一步。区分“已观察到的现象”“主流解释”“仍在估算的细节”；不把有共识的机制和缺少依据的猜想并列成同等可信，也不把模型估计写成现场实测。不能只加“一种解释是”就保留无出处的说法。
- 标明台词属于原研究直接结果、基于研究的解释，还是生活类比；不要让一条研究看起来支持它没有研究过的状态或人群。
- 记录会改变结论的适用条件和争议；必要时缩窄台词，不用讲故事的顺滑度覆盖证据边界。
- 同步写进工作台 `facts` 字段（每条 `{o, claim, url}`）。

## 7. 标题、封面文案、评论区

**封面大字**：不超过 12 个字为宜，分两行（用 `/` 分隔），最戳人的一个词用克莱因蓝（写进 `coverHighlight`）。同时在 `story.js` 的 `COVER.bg` 和 `COVER.pop` 为本期选两种高对比色：背景用明亮且饱和的颜色，人物背后用撞色形状；黑字和蓝色关键词必须清楚可读。不同期轮换色组，不要每期都用同一套黄红，也不要让画面变成无层次的彩虹。

**各平台标题**（写进 `mat.<平台>.title`）：

| 平台 | 写法 | 长度 |
|---|---|---|
| B 站 / YouTube | 问题 + 反转或机制名，可以长 | ≤ 80 字 |
| 抖音 / 快手 | 短、带情绪、口语 | ≤ 30 字 |
| 小红书 | 第一人称、带感受词（“终于想通了”“原来……”） | ≤ 20 字 |
| 视频号 | 家庭类选题写成“转给爸妈看”的口吻 | ≤ 30 字 |

**简介**（`mat.<平台>.desc`）：三句话——本期问题、核心机制一句话、评论区问题。B 站和 YouTube 后面附章节。

**标签**（`mat.<平台>.tags`）：3–6 个，空格分隔，包括 `#白洞`、选题关键词、领域词（心理学 / 经济学 / 社会学）。

**评论区置顶语**：一句片中没说完的补充，引导讨论。

**小红书 6 张卡片**（`xhsCards`，每张 `{o, head, body}`）：生活题可按“封面问题 → 具体场景 → 关键困惑 → 原因解释 → 可试的小动作 → 互动”组织；历史科学题可改成“问题 → 已知现象 → 关键线索 → 因果解释 → 结论与边界 → 互动”。没有真实误解时不硬造“你以为”，不把特别企划改写成生活鸡汤。每张 head ≤ 12 字，body ≤ 60 字。
