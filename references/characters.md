# 白洞 · 角色设定

画法：科幻情景喜剧卡通（lemo-opuscar `scifi-toon`），执行细则见 skill 内 `references/visual.md`。会抖动的粗线条（12 fps 换三张线稿）、平涂、硬边阴影、大眼睛小瞳孔。
主角主体保持墨黑 `#111111`、纸白 `#FFFFFF` 和黑白灰层次，老白保留克莱因蓝围巾 `#002FA7`。场景、道具、说明图和临时人物可使用鲜明彩色，按场景组织三至五种主色；不限制全画面只能出现一处蓝色。

本文件与 skill 内 `references/characters.md` 同步维护。角色身份和造型以本设定为准，场景配色与镜头表演按 `references/account.md` 和 `references/visual.md` 执行。

**生产用的绘制代码**：skill 根目录下的 `assets/episode-template/chars.js`，每期新建项目时复制一份。改角色时检查本期使用的代码及后续模板是否都需同步，再重新渲染角色展示板核对。

- 全身：`laobai(P)`、`xiaowen(P)`。常用参数：`x, y, s`（位置和缩放）、`face`（1 朝右 / -1 朝左）、`view`、`expr`（表情名）、`talk`（口型）、`blink`、`armF / armB`（手臂）、`lean`、`headTilt`、`bob`、`walk`、`sit`。
- **四个角度** `view`：`'q'` 3/4 侧面（默认）、`'front'` 正面、`'side'` 正侧面（朝右，配 `face: -1` 朝左）、`'back'` 背面。
- **常用动作** `POSES`：用法 `laobai({ x, y, ...POSES.laobai.explain, talk })`。
  - 老白：`stand` 站立、`explain` 讲解、`point` 指向、`think` 思考、`shrug` 摊手、`cross` 抱臂、`walk` 走路、`sit` 坐
  - 小问：`stand` 站立、`raise` 举手提问、`shocked` 震惊（自动发抖）、`defiant` 不服、`sad` 委屈、`aha` 恍然大悟、`walk` 走路、`sit` 坐
  - 走路动画：每帧把 `walk` 设成当前时间 `t` 即可，`stride` 调步幅。
- 头部单独画（封面、特写用）：`headLaobai / headLaobaiFront / headLaobaiSide / headLaobaiBack`，`headXiaowenQ / headXiaowen（正面） / headXiaowenSide / headXiaowenBack`，参数是表情 `E`。
- 临时人物：`extra(P)`，可用 `coat` 和 `coatS` 设置衣服及硬边阴影色；按场景对比需要选色。

**本机展示板**（转面图和动作表）：`G:\vibe\baidong-brand\turnaround\out\`，源码在 `turnaround\main.js`。早期设计稿在 `characters-v2\`（含嘉宾）。这些是本机可选参考，未随 skill 包附带；其他机器用随包的角色代码制作样帧。

## 主角（2026-10-25 确定，方案 C1）

### 老白 · 主讲
- **性格**：冷面、话少、语速慢，见过很多事，一句话戳穿真相。负责讲机制。
- **造型**：蛋形脸，光头上翘着一根倔强的头发；厚眼皮、眼袋、长鼻子；黑色连帽衫，胸口印着白洞标志（白圈、细环、黑点）；**克莱因蓝围巾**（角色识别点）；灰裤子、黑鞋。
- **表情预设**：平静 `{}` · 看透了 `{ lid: .3, brDy: 12, m: { sm: .5, skew: .4 } }` · 无语 `{ lid: .78, look: [.6, 0], m: { sm: -.6, w: .6 } }`
- **配音**：`zh-CN-YunjianNeural`，语速 −6% 到 −10%，音调 −4Hz；后期加轻微饱和和 180 Hz 低频，让声音更沙哑。

### 小问 · 提问者
- **性格**：好奇、容易急，替观众问出心里那句“凭什么”“为什么”。负责共情和吐槽。
- **造型**：圆脸、黑色齐耳短发，头顶一撮**问号形状的头发**（她的标志，每个镜头都要看得见）；特别大的眼睛；黑白横条纹 T 恤、黑短裤、白袜、黑色大球鞋。
- **表情预设**：疑问 `{ m: { o: .25 }, look: [.3, -.4] }` · 震惊 `{ eS: 1.2, pupil: 2.6, bl: 1.5, br: 1.5, m: { o: .9, w: 1.2 }, sweat: true }` · 不服 `{ bl: -1, br: -1, m: { sm: -.8, skew: .5 }, look: [-.3, .2] }`
- **配音**：`zh-CN-XiaoyiNeural`，语速 +6% 到 +14%，音调 +6Hz；后期提亮 3.2 kHz。

两人同框时，老白高、小问矮，剪影一眼能分开；小问保留黑白条纹造型，老白保留蓝围巾。场景和道具可以出现蓝色，以明暗和构图保护角色识别点。

## 表演与镜头

- 老白也可以被问住、嘴硬或改变主意；小问有自己的判断和行动。谁受到冲击，就给谁反应近景，不固定只拍小问。
- 预设是动作起点，关键动作有预备、动作与收势；用视线、眉毛、嘴型、`lean`、`headTilt` 和手势配合，不靠循环嘴动完成整场戏。
- 看票、操作装置、松手等动作需要可读的过程；持物跟随手掌。通过实际镜头连续帧核对，不把规则已补齐说成动作已经制作完成。
