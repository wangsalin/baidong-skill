新期采用不同角色提问与解答，默认D1有戏提问、B2小算盘解答。按商业经济问题换组合时仍从八位正式人物中选择，核实对应声音认可状态；不改身份、性格和固定声音。问题后立即给直接答案，再由解答者连续说明原因与条件。个性用语气、措辞与必要的简洁判断体现，不增加剧情、捧哏或轮流拆句。

### 声音确认与可运行状态

`assets/episode-template/voice-reference.json` 是逐角色声音确认记录。八条历史免费 Edge 试听保留。2026-11-02，用户在获知当前开店视频为preview后明确要求“按照正式版给我做！”，本次B2小算盘、D1有戏中英文现有映射据此记录正式制作授权，附本期实际处理后的样音、参数及指纹。该记录表示沿用当前声音制作正式文件，不冒称用户逐条试听或发表音色偏好；其余六人的中文candidate、英语unreviewed状态不变。

- preview：允许制作带水印的测试样片，不会触发付费供应商。
- final：只接受本期出场角色的 approved 记录，且必须有真实确认依据、样音文件指纹、voice/rate/pitch 和 voice.py 后处理版本。缺少任一项立即阻止。
- 用户确认应针对当前后处理后的具体样音；只在收到明确反馈后维护对应角色记录。不能自动填“已认可”、拿公开试听替代正式映射，或为了出片取消检查。

### 生产调用规则

- `lines.json` 的 `who` 使用 `A1`–`D2`，并填写该角色对应的 `voice`、`rate`、`pitch`。模板中的 `check-characters.py` 检查八个固定姓名、ID、声音、语速和音调；`check-production.py` 另检查固定资产与最终声音确认状态。
- `assets/episode-template/chars.js` 是镜头调用入口：`character('A1', P)`。`brand.js` 和 `srt.mjs` 从同一注册表显示姓名，避免字幕叫错人。
- `assets/episode-template/voice.py` 按人物 ID 做固定后处理。不能在不同内容形式里给同一个 ID 换声线。
- `LAOBAI`、`XIAOWEN` 只作为旧期工程兼容别名，不属于新的八人角色库；`本我`、`自我`、`超我`、`同事`是剧情中的临时叙事身份，不能写进正式角色表。

画法：科幻卡通（lemo-opuscar `scifi-toon`），执行细则见 skill 内 `references/visual.md`。会抖动的粗线条（12 fps 换三张线稿）、平涂、硬边阴影、大眼睛小瞳孔。上游风格名或旧情景喜剧示范只说明画法，不要求新期演戏。
八位人物主体保持各自确认稿的黑白灰层次和识别配饰，不能把所有人改成同一条围巾。场景、道具、说明图和临时人物可使用鲜明彩色，按场景组织三至五种主色；不限制全画面只能出现一处蓝色。

本文件与 skill 内 `references/characters.md` 同步维护。角色身份和造型以本设定为准，场景配色与镜头表演按 `references/account.md` 和 `references/visual.md` 执行。

**确认稿**：`assets/identity-reference/identity-lineup.png` 与冻结的 `cast.js`。**生产用的绘制代码**：skill 根目录下的 `assets/episode-template/chars.js`，每期新建项目时复制一份。改角色时检查本期使用的代码及后续模板是否都需同步，再重新渲染角色展示板核对。

## 正式人物的绘制与动作

- 全身统一使用 `character('A1', P)`，角色 ID 来自 `characters.js`；姓名、服装和配饰保持八人注册表中的设定。
- 默认 `q` 造型恢复自用户确认的四组设计源码，八人与独立冻结参考逐像素对照。`front/side/back`、走路和坐姿目前为派生预览，并未独立获确认；正式阶段禁止调用这些未确认姿态，避免用通用转面替换人物。
- `FORMAL_POSES[id]` 提供 `stand/explain/point/think/shrug/cross/walk/sit`，另有 `front/side/back` 转面预设。用 `character(id, {x,y,...FORMAL_POSES[id].sit})` 画坐姿；走路把 `walk` 设为当前时间 `t`，不把预设的单帧值当持续动画。
- 表演继续通过 `expr/E`、`headTilt`、`lean`、`armF/armB`、`blink` 与 `talk` 控制；预设只是动作起点。坐姿有座椅、弯曲的大腿和小腿；转面不是更名或镜像同一张脸。
- 运行 `LIB=... node scripts/test_characters.mjs <QA输出目录>` 可检查八人角度/动作差异、默认造型保持、镜外人物、错人出镜和转场抢话，并输出动作总览。基准保存在随包的 `assets/identity-reference/`，不需要 Git 历史。动作像素变化只证明参数有效，不能证明派生造型已认可。迁移后的成片仍运行项目自身 `check-cast.mjs`。

## 历史双人绘制 API（仅旧工程）

- 全身：`laobai(P)`、`xiaowen(P)`。常用参数：`x, y, s`（位置和缩放）、`face`（1 朝右 / -1 朝左）、`view`、`expr`（表情名）、`talk`（口型）、`blink`、`armF / armB`（手臂）、`lean`、`headTilt`、`bob`、`walk`、`sit`。
- **四个角度** `view`：`'q'` 3/4 侧面（默认）、`'front'` 正面、`'side'` 正侧面（朝右，配 `face: -1` 朝左）、`'back'` 背面。
- **常用动作** `POSES`：用法 `laobai({ x, y, ...POSES.laobai.explain, talk })`。
  - 老白：`stand` 站立、`explain` 讲解、`point` 指向、`think` 思考、`shrug` 摊手、`cross` 抱臂、`walk` 走路、`sit` 坐
  - 小问：`stand` 站立、`raise` 举手提问、`shocked` 震惊（自动发抖）、`defiant` 不服、`sad` 委屈、`aha` 恍然大悟、`walk` 走路、`sit` 坐
  - 走路动画：每帧把 `walk` 设成当前时间 `t` 即可，`stride` 调步幅。
- 头部单独画（封面、特写用）：`headLaobai / headLaobaiFront / headLaobaiSide / headLaobaiBack`，`headXiaowenQ / headXiaowen（正面） / headXiaowenSide / headXiaowenBack`，参数是表情 `E`。
- 临时人物：`extra(P)`，可用 `coat` 和 `coatS` 设置衣服及硬边阴影色；按场景对比需要选色。

**旧版本机展示板**（仅历史参考，不能替代八人确认稿）：`G:\vibe\baidong-brand\turnaround\out\`，源码在 `turnaround\main.js`。早期设计稿在 `characters-v2\`（含嘉宾）。这些是本机可选参考，未随 skill 包附带；其他机器用随包的角色代码制作样帧。

## 旧版角色兼容（老白 / 小问）

以下两位只用于已存在的旧期工程，不能作为新八人角色库的替代名称。新期优先使用上面的 A1–D2 注册表。

### 老白 · 主讲
- **性格**：冷面、话少、语速慢，见过很多事，一句话戳穿真相。负责讲机制。
- **造型**：蛋形脸，光头上翘着一根倔强的头发；厚眼皮、眼袋、长鼻子；黑色连帽衫，胸口印着白洞标志（白圈、细环、黑点）；**克莱因蓝围巾**（角色识别点）；灰裤子、黑鞋。
- **表情预设**：平静 `{}` · 看透了 `{ lid: .3, brDy: 12, m: { sm: .5, skew: .4 } }` · 无语 `{ lid: .78, look: [.6, 0], m: { sm: -.6, w: .6 } }`
- **配音**：`zh-CN-YunjianNeural`，语速 −6% 到 −10%，音调 −4Hz；后期加轻微饱和和 180 Hz 低频，让声音更沙哑。

### 小问 · 提问者
- **性格**：好奇、容易急，替观众问出心里那句“凭什么”“为什么”。负责共情和吐槽。
- **造型**：圆脸、黑色齐耳短发，头顶一撮**问号形状的头发**（她的标志，每个镜头都要看得见）；特别大的眼睛；黑白横条纹 T 恤、黑短裤、白袜、黑色大球鞋。
- **表情预设**：疑问 `{ m: { o: .25 }, look: [.3, -.4] }` · 震惊 `{ eS: 1.2, pupil: 2.6, bl: 1.5, br: 1.5, m: { o: .9, w: 1.2 }, sweat: true }` · 不服 `{ bl: -1, br: -1, m: { sm: -.8, skew: .5 }, look: [-.3, .2] }`
- **配音**：`zh-CN-XiaoyiNeural`，语速 +6% 到 +14%，音调 +6Hz；后期提亮 3.2 kHz。

两人同框时，老白高、小问矮，剪影一眼能分开；小问保留黑白条纹造型，老白保留蓝围巾。场景和道具可以出现蓝色，以明暗和构图保护角色识别点。

## 历史双人表演与镜头（仅旧工程）

本节保留旧片维护所需说明；新期主讲与解释画面执行 `content.md`、`visual.md` 和 `production.md`，不按以下说明新写双人剧情。

- 老白也可以被问住、嘴硬或改变主意；小问有自己的判断和行动。谁受到冲击，就给谁反应近景，不固定只拍小问。
- 预设是动作起点，关键动作有预备、动作与收势；用视线、眉毛、嘴型、`lean`、`headTilt` 和手势配合，不靠循环嘴动完成整场戏。
- 看票、操作装置、松手等动作需要可读的过程；持物跟随手掌。通过实际镜头连续帧核对，不把规则已补齐说成动作已经制作完成。
