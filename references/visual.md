# 白洞 · 主讲与商业经济解释画面

写分镜、设计图表和资料窗、制作封面与检查成片时使用。账号配色见 `account.md`，角色造型与参数见 `characters.md`，封面见 `covers.md`，执行命令见 `production.md`。

沿用 Lemo-Opuscar 的 Sci-Fi Sitcom Toon（`scifi-toon`）画法、既有品牌、字体、八位角色与声音。上游风格文档、旧《沉没成本》参考及模板自带对白用于画法和技术参考；新期按用户2026-11-04确认的双角色直接问答制作：本期选定的提问者发问、另一角色立即解答，不增加情景喜剧、生活目标、人物冲突、操作科幻装置或剧情反应。

## 1. 解释需要怎样的画面

先有讲稿和证据，再确定画面。每个关键画面注明：对应哪句解释、显示什么对象与关系、数据或资料来自哪里、先看哪一步。主讲把必要定义与因果说完整，画面帮助观众看懂金额、流向、比较或变化。

按内容选择资金流、收入成本拆分、可比图表、时间线、报告原页、产品或门店资料、简短说明性插图。资金箭头、数字和条件随解释出现；已讲清的信息可以保留作参照，不在每句重新播放同一套动画。无需给画面编人物遭遇、争吵、旅行或成功结局。

假设账本、演算和类比清楚标注，真实数据显示实际来源、期间、单位与统计口径。图表不得用截断坐标、改变分母或省略重要条件制造反差；技术外观不能把假设包装成实测。画面太满时减少次要信息，不以角色接话填补阅读时间。

### 每期独立设计与跨期对比

固定渲染壳、人物画法、品牌和声音可复用；单期构图、场景空间、主要道具、解释动画与资料按当前内容设计。允许轮换视觉主题和角色组合，一期内保留对象与颜色的连续性。随机选择不改变事实，不要求每句话切镜或临时换人。

先确定本期要看懂的具体对象与变化，再设计主镜头。例如顾客复购适合顾客批次、到店路径、成本缺口及回访时间线；资金分账适合付款主体与流向。例子用于选择，不固定所有新期都用这些结构。让画面展示关系与变化，避免把整期做成主讲站在同一位置、说明板逐页换字。

制作前查看最近一期成片总览，比较开头、核心解释与结尾的主体、构图、场景、人物位置及B-roll。主题不同却只换标题、数字、颜色或角色时，重新设计分镜；必要的同对象资料可复用并说明用途，不机械禁止一切重复。把比较与本期选择记入现有TREATMENT.md，正式输出后用同样的代表帧核对。技术校验、字幕可读不能替代本项视觉判断。

## 2. 画法与色彩

- 粗深色轮廓、平涂、硬边阴影、大眼白和小瞳孔。避免柔光渐变、塑料立体感和光滑图标式人物。
- 沿用 `toon.js` 的屏幕空间描边：人物和主要道具约 7 px，背景细节约 4–6 px。推近镜头时线宽保持稳定；线稿按 12 fps 在三组轻微扰动间切换，背景可降低抖动幅度以保证阅读。
- 人物姿态、口型和眨眼按 12 fps 换形；摄像机、飞行道具和转场按成片的 24 fps 连续变化。
- 每个主要场景选三至五种主色，区分主色、对比色和强调色。高饱和色用在关键道具和视觉重点，背景保留明暗层次；连续发生的动作保持配色连续，不因换一句台词就换世界。
- A1–D2 保持各自注册表中的黑白灰主体、体块和识别配饰。场景、图表、道具和临时人物可用彩色；A1 的蓝色长围巾不限制全画面的蓝色使用。优先调整背景位置和明暗，保持每位人物的配饰、轮廓和字幕清楚。
- 图表、资料与插图保持主体和关系清楚，不统一套霓虹光。确有科幻示意时可用少量平面半透明色环；涉及地点或实物时再交代必要空间，不为讲解强加生活场景。

## 3. 主讲姿态与口型

- 每期从A1–D2正式库轮换或随机选择两位不同角色完成问答。保持各自确认稿角度、服装、配饰和体块。解答者连续讲清必要内容，不增加扮无知、争执或捧哏。
- 问答交接时让观众看清当前发声者，字幕姓名与本人音色一致。可以切单人画面或两人同框，实际说话者在整个发声区间清晰可见；逐次检查交接前后连续帧，避免问题未说完就换脸或答案响起仍只显示提问者。
- 用视线、眉毛、`headTilt`、`lean`、`armF/armB` 和既有手势强调当前解释，口型由本人的真实音轨驱动；不让无关角色替他说话或用循环空嘴动代替口型。
- 主讲可与图表同框，也可在资料占主体时置于清楚可见的侧栏或画中画。须保留能辨认的本人头脸和真实口型，不以静态头像、姓名条或他人的脸承接声音；所有发声区间仍通过 `check-cast.mjs`。
- 自然眨眼、姿态与手势足以支持主讲，不为证明“有表演”插入惊讶、冲突或反应近景。发生手势或持物时再检查预备、过渡、收势与遮挡，不要求每镜安排动作。

## 4. 镜头跟随解释

| 要看懂什么 | 可用的画面 |
|---|---|
| 今天研究什么、主讲的关键判断 | 主讲与问题或关键对象同框 |
| 谁付钱、钱流向谁 | 带主体名称与金额条件的资金流图 |
| 营收、成本与利润的关系 | 账目拆分或同口径对照，保留单位与主体 |
| 一个指标怎样变化 | 时间序列、阶段对比或可复算的图表 |
| 关键说法的依据 | 报告原页或资料窗，突出关键行并保留上下文 |
| 方法或条件之间的差别 | 分点、并列或流程图，按口播逐步展示 |

切镜、推近或图表高亮应让观众看清新的信息，不按固定秒数切换机位。主讲连续讲话时可以保持稳定构图；画面不是逐句换背景，也不以整屏文字照抄口播充当解释图。

在本期分镜写明上一镜的问题与下一镜增加的信息。相同对象保持颜色、位置与方向一致，比较时尽量固定参照物和口径。硬切、局部推近、图表过渡与既有白洞圆环按信息变化使用，不为跨页额外编装置或剧情。

验收转场时查看切点前后连续帧，确认遮罩覆盖、新画面出现、没有回露旧画面；竖屏检查四角。图表动画检查数字、箭头和高亮与讲解时点相符，不只凭低频总览图判断。发声角色在切镜和转场中继续满足既有可见范围校验。

### 真实资料与 B-roll

B-roll 是辅助讲解的资料镜头。横版、主力短竖版与完整竖版均按解释需要主动寻找真实图片、视频和报告原页，优先使用与本句解释有关、来源可追溯且使用条件允许的资料，不设每期固定数量或占比。短版也要按实际台词接入对应资料，不能以保留卡通画法为由省略素材研究；确无可用素材时记录原因，使用有依据的自制图表。

- **查清画面是什么**：核对来源、作者/机构、拍摄或发布日期、地点和事件；无法确认的项目标为未确认。真实门店空镜只能说明所见场景，不能证明倒闭率或某家店亏损；非本事件素材标为场景参考，AI生成或摆拍标为情景演绎，不冒充实拍证据。
- **查清能怎样使用**：优先用户自有、已授权或许可条件明确的素材；公开可看不等于可直接复用。记录适用的使用依据和署名要求，不能确认时保留为候选，不进入正式成片，不去水印伪装自有。无可用素材时可用可复核的自制图表，不把生成图片当真实资料替代。
- **与台词和证据对应**：在本期分镜或 `TREATMENT.md` 记录素材对应的台词/事实ID、用途、拟用片段和标注。报告原页放大关键行时保留足以识别来源、期间、单位和脚注的上下文；裁切、加速或重排不能改变原意。
- **继承白洞画面与出镜规则**：真实素材可作为资料窗、越肩屏幕、对照镜头或带人物画中画的画面，沿用本期色彩、字体、字幕安全区和既有模板。有人物台词时，实际说话角色继续可见并按本人音轨驱动口型，通过 `check-cast.mjs`；不以头像、姓名字幕或他人代替。全屏资料空镜可放在无人物台词的间隙。
- **本地固定并留出处**：进入制作的素材保存为本期本地文件，视频片段记录原片时间范围；在已有 `CREDITS` 中记录文件名、原始链接、作者/机构、日期、使用依据、必要标注及使用位置，素材清单保留文件指纹。候选、已核实可用、已入片要区分，找到链接不等于已取得或已使用素材。交付时说明实际使用的是照片、报告节选还是动态视频，照片推近不称为动态实拍。
- **四版各自验收**：横竖版分别检查裁切后是否失去上下文、来源与字表是否可读、素材原声是否干扰固定角色配音；英文版保留原资料身份并适配译注。真实资料、统计图、假设演算和说明性插图在画面中清楚区分。

## 5. 节奏和声音

主讲保持自然、连贯，重要定义和因果说完整。停顿用于换气、理解数字、阅读关键证据，不为演人物反应或撑时长。可在 `BEATS` 使用已有 `pause` 和 `mark` 对齐资料、图表和手势；字幕按语义分屏，四版全部单行。

沿用固定配音参数和角色后处理，不额外加速塞稿。配乐优先按用户音乐库选择，关键解释不被音乐或音效盖住；不为每个关键词加冲击音。综合响度与语音清晰度分别检查，用实际成片回听或听写复核，自动识别不能替代真人听感确认。

## 6. 解释画面的验收

观众应能跟着口播理解对象、条件、因果或比较，并知道数据或案例实际支持什么。主讲直接说必要定义与原因，画面展示对应关系，不将核心答案藏在难读的小字里。

例如用假设门店账目解释利润：同一期间的收入、成本和费用分别列清，保留计算关系并标为假设；若使用真实企业数据，则核实主体、期间、是否含税和费用范围，不把集团利润画成单店利润。

进入制作后，用本期真实绘制代码检查问答角色与主题同框、关键图表或资料画面等代表性样帧。每次角色交接、重要数据变化、转场和实际发生的手势按约0.2秒间隔检查连续帧；不要求人物冲突或剧情反应样帧。八人身份确认稿与原有资产校验继续执行。

最终MP4另外检查每2秒总览、问答及切镜连续帧、各处B-roll起中末帧与片尾，原图和手机缩略尺寸核对封面。实际查看后才登记视觉结论，并绑定当前成片与封面的SHA256；重渲染后重新核对，不能沿用旧片结果。自动检查、抽帧目视与真人带声试听分别如实记录。

整片带声音检查主讲与口型、图表变化、单位与来源、字幕遮挡、色彩层次、语速与停顿。只修订规则时如实报告文档与工具验证，不声称新片效果或流量已经验证。
