# 白洞 · 卡通商业问答的画面与声音

分镜和验收时使用。定位见 account.md，人物见 characters.md，命令见 production.md，竖版见 vertical.md。

## 内容与风格

不同角色直接提问与解答，保持商业经济定位、必要因果及明确判断。去掉冗长剧情铺垫、捧哏和无效接话；场景、视线、表情、动作和反应近景可以直接帮助解释，不因“无剧情”而取消。

采用 Sci-Fi Sitcom Toon 的手绘电视动画画法和镜头语法：人物与物件处于可理解的空间，景别随关注对象变化，动作回应信息，粗线和平涂有体块与遮挡。原版 STYLE.md 是画法参照，DEMO.md 和 Coffee Run 是镜头参考，不复制其人物、咖啡故事、传送旅行及喜剧停顿结构。规范在上游 styles/scifi-toon/STYLE.md，官方示例在 GitHub Releases 的 films/scifi-toon.mp4。

2026-11-05 修订样段见 [参考说明](../assets/examples/scifi-business-style-proof/README.md)：包含横竖视频、同题修正前后与原版的画面对照，以及本段镜头源码。只参考空间、动作和取景方法，每期按内容另设计场景。本轮核对上游 main `bebbbe1aa92a3cb4bb6f83500e61b23a17d1aa00`，scifi-toon 子树与本地制作库一致。

## 先设计观众看什么

每镜明确关注对象、新增信息、视线落点、物件变化和必要声音。账单、柜台、产品、订单和报告原页可成为主镜头，不把所有解释套进同一张讲解板。

同空间对象保持位置、比例及前后关系：人站在柜台前，账单在台面，手能指到具体项；背景预留推近和横移范围。复杂图表和真实资料可独立全屏。空间不等于每镜必须有地板，也不为讲数字编经营故事。

问答交接时用双人中景、人物近景、视线及姓名建立身份。人物可同框倾听；连续解释可切到物件或资料。避免说一句就替换整个人，也避免人物始终缩在角落。

| 信息目的 | 可选镜头 |
|---|---|
| 问题与人物关系 | 带关键对象的双人中景或近景 |
| 谁付钱、哪项有问题 | 手、账单或支付屏幕的插入特写 |
| 判断与纠正误解 | 解答者近景，眼神、眉毛和简洁手势呼应 |
| 计算与规模变化 | 同口径图解，从一个对象展开到一批 |
| 证据 | 报告关键行、产品或真实资料占据主体 |
| 收束立场 | 回到人物与关键对象，用动作或短停顿完成判断 |

按内容选择，不机械用完镜头清单，不按固定秒数切镜。原版示例的镜头密度不是财经解说硬指标。图表需要理解时稳定停留，下一镜增加观看角度或信息，不能只换字和底色。

## 画法与人物动作

- 八人身份、轮廓、服装、配饰及固定声音沿用。每期可轮换或随机选不同问答角色，一期及对应语言版本分工一致。未确认派生转面按 characters.md；同一确认角度也能完成近景、对视与看账。
- 粗深线、平涂、硬边暗面、大眼白、小瞳孔。形体内部裁切的暗面交代脸、衣服和道具体块，保留遮挡；避免柔光渐变和塑料感。不能用线稿扰动替代空间设计。
- 人物和主要道具屏幕空间描边约7px，背景约4–6px，推近不放粗轮廓；三组轻微线稿按12fps切换。人物姿态、口型和眨眼按12fps换形，摄像机及飞行物按24fps连续变化。
- 本人真实音轨驱动口型，闲置口型闭合。视线看搭档、物件或观众，随语义变化；眉毛、眼皮和嘴角表达判断，不靠循环摇头承担表演。
- 有意义的手势写预备、执行、收势，用关键帧插值；指向有具体落点，手掌和道具同步，检查肩臂与遮挡。轻微呼吸可用 sq；强挤压拉伸按内容需要使用。
- 正式角色可传 `celShade:true` 添加裁切硬边暗面；不传时保持确认稿。按当前光源检查朝向，不用暗面遮住识别配饰。
- 冷眼、质疑和理解后的停顿都可成立。反应近景推进理解时使用，不强加喊叫或冲突。
- 每场景3–5种主色，同空间连续，场景关系变化再调整；八人黑白灰和蓝色配饰保留，通过背景、道具和明暗组织注意力。

## 出镜与插入镜头校验

默认逐帧核对实际发声者本人脸部与口型，不允许错人代说或意外遮挡。物件/资料承接连续解释时，在场景函数中明确调用从 ctx 注入的 present：

```js
present({mode:'insert', speaker:'C1', subject:'教学假设的首单账单'});
// 真实资料使用 mode:'broll'。
```

每帧默认重置为出镜模式。check-cast.mjs 要求当前说话者在本轮发言先清楚出镜，再进入声明的镜头；speaker对应真实声音、subject非空、没有其他人物代动嘴、没有转场意外遮挡。未声明的消失仍判失败。声明通过不能代替实际画面的声音归属和资料身份检查。

## 真实资料与数据

横竖版按解释需要研究真实图片、视频和报告，不规定素材占比。资料可独立全屏、越肩或同框，不强制旁边常驻小人。

- 核对来源、作者/机构、日期、地点和事件。门店空镜不证明亏损或团购效果，参考素材明确标注，生成/摆拍不能冒充实拍。
- 使用用户自有、已授权或许可明确的素材，记录署名条件。公开可看不等于可直接复用；无法核实保留候选，不入正式片。缺素材时用可复核自制图并记录。
- TREATMENT.md 对应台词/事实ID、用途及片段。报告保留主体、期间、单位和脚注上下文；不通过裁切改变原意。
- 素材固定为本地文件，CREDITS记录链接、作者/机构、日期、使用依据、位置及必要标注，保留文件指纹。候选和已入片区分，照片推近不称动态实拍。
- 真实数据、教学假设、类比和说明图区分，金额与口径在相关镜头可辨。图表不以截断坐标、换分母或省略条件制造反差。各语言/比例独立检查裁切、字体及原声。

## 声音与节奏

解答自然连贯，停顿服务换气、理解和判断，不照搬喜剧冷场或撑时长。固定声音及后处理沿用。

从用户音乐库选曲，规划进入、收束和必要短停，保留用户偏好的音乐存在感，不只调大全片音量。落账单、核销、翻页等必要动作配对应声音，不给每次切镜统一加冲击音。可用J/L-cut连接真实资料。实际成片检查对白可听、数字完整、动作音对齐；ASR不能代替听感。

`episode.json` 可设 `cut_sfx:false` 关闭普通切镜自动音效，必要动作音单独通过 `BEATS` 的 `fx` 排入。

## 验收与跨期变化

风格修订或首次采用新场景方法，先做覆盖问答、物件近景和动作衔接的代表样段，验证后扩展授权范围；样段不冒充四版整期，已授权执行不反复确认。

1. 本期代表帧与原版并排，比较空间、景别、人物大小、体块、视线与动作。去掉字幕后仍可辨当前对象和变化；资料依赖文字时检查重点可读。
2. 对比最近一期开头、核心解释、结尾和素材，不能只换人、换色、换数字。比较需要的同构图保留参照。
3. 动作、交接、资料起止及转场按约0.2秒查看连续帧，图表与真实口播对时。横竖各自取景，避免默认上图下小人。
4. 最终MP4检查每2秒总览、关键原尺寸帧和片尾，记录绑定当前媒体指纹；再完整带声检查阅读、音乐、口型与动作。未实际带声观看如实记录。

身份像素、ASR、声画绑定和文件完整性分别证明技术事项，不能证明风格效果或流量。留存与广告效果由发布数据验证。
